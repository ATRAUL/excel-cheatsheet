Functions & Formulas

The formulas that do the actual work — lookups, conditional logic, financial math, date handling, and text manipulation.

Lookup Functions

Pull a value from one place into another based on a matching key.

VLOOKUP

Find a value in the leftmost column of a table, return a value from a column to its right.

=VLOOKUP(lookup_value, table_array, col_index, [range_lookup])

Best for:

  • Quick lookups where the data layout is fixed
  • Pulling a single field using an ID

Watch out for:

  • Can't look left — key column must be column 1
  • Inserting a column inside table_array breaks it
  • Slower than INDEX/MATCH on large datasets

Always use FALSE (or 0) as the last argument for exact match.

Animated example — finds Carol's department
=VLOOKUP("E003", A2:D5, 3, FALSE) → Engineering

INDEX / MATCH

A more flexible two-function combo — works in any direction, survives column changes.

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

How it works:

  • MATCH finds the row position of the lookup value
  • INDEX returns the value at that position from the column you choose

Best for IB because:

  • Doesn't break when columns shift
  • Can look left as well as right
  • The IB industry standard

XLOOKUP note: Excel 365/2019+ has XLOOKUP which combines both. Use it personally, but learn INDEX/MATCH for compatibility.

Animated example — INDEX/MATCH style

Logical & Conditional Functions

Branching logic and conditional aggregation. Used in basically every IB model.

IF

Branch on a condition.

=IF(condition, value_if_true, value_if_false)

Examples:

=IF(A1>100, "High", "Low")
=IF(Revenue>Budget, Revenue-Budget, 0)

Nesting: If you nest more than 2 deep, switch to IFS or a lookup table.

IFERROR IB

Wraps a formula to show a clean fallback when it errors. Used in every model.

=IFERROR(formula, value_if_error)
=IFERROR(VLOOKUP(A1, Data, 2, FALSE), "Not found")
=IFERROR(B1/C1, 0)

Without it, missing lookups or divide-by-zero blow up your whole model.

Caution: Don't blanket-wrap everything — errors sometimes signal real bugs.

SUMIFS IB

Sum a range only where multiple conditions are met.

=SUMIFS(sum_range, criteria_range1, criteria1, ...)

Example: total Q1 revenue from the North region:

=SUMIFS(Revenue, Region, "North", Quarter, "Q1")

Operators in criteria: ">100", "<=50", "*Inc*" (wildcard).

Sister functions: COUNTIFS, AVERAGEIFS, MAXIFS/MINIFS.

COUNTIFS

Count rows where multiple conditions hold.

=COUNTIFS(criteria_range1, criteria1, ...)
=COUNTIFS(Status, "Closed", Region, "EMEA", Year, 2026)

Financial Functions

The valuation building blocks. XNPV and XIRR handle real (irregular) dates.

NPV & XNPV IB

Present value of cash flows discounted at a rate.

=NPV(rate, cashflow1, cashflow2, ...)
=XNPV(rate, cashflows, dates)

Critical NPV gotcha: Excel's NPV assumes the first cash flow is at the END of period 1. If you have a t=0 investment, add it outside:

=A1 + NPV(rate, B1:Z1)

Use XNPV instead when you have actual dates — uses precise day-count and handles t=0 correctly.

IRR & XIRR IB

The discount rate that makes NPV equal zero — the implied return.

=IRR(cashflows, [guess])
=XIRR(cashflows, dates, [guess])

First cash flow is typically negative (initial investment). Use XIRR for irregular dates.

PMT

Periodic payment for a loan with constant rate.

=PMT(rate, nper, pv, [fv], [type])

Example: monthly payment on a $500k mortgage at 6% APR for 30 years:

=PMT(6%/12, 30*12, 500000)

Result is negative (cash outflow). In LBOs, used to size mandatory debt amortization.

Date Functions

For fiscal periods, partial-year discounting, and anything time-aware.

End of month, optionally offset by N months IB
=EOMONTH(start, months)
=EOMONTH(TODAY(),0) = last day of this month.
Same date N months later
=EDATE(start, months)
Fraction of a year between two dates IB
=YEARFRAC(start, end, [basis])
For partial-year DCF discounting. Common basis: 0 (30/360) or 1 (actual/actual).
Build a date from year/month/day
=DATE(year, month, day)
Today's date (auto-updates)
=TODAY()
Volatile. Use Ctrl+; for static.

Text Functions

Cleaning up data dumps from clients and building dynamic labels.

Format a number as a custom-formatted text string

=TEXT(A1, "$#,##0.00")

Cleaner than CONCATENATE.
Extract characters from left, right, or middle
=LEFT(text, n)
Also RIGHT and MID(text, start, n).
Remove extra spaces
=TRIM(text)
First thing to try when VLOOKUP returns #N/A.
Length of a text string
=LEN(text)

Pro Tips & Conventions

The unwritten rules of IB Excel work.

The font color convention (memorize on day one)

  • Blue — hardcoded inputs
  • Black — formulas in this same sheet
  • Green — links to other sheets
  • Red — links to other workbooks

Blue = fair game. Black = stop, you're about to break a formula.

F4 is your most-used key

  • A1 — fully relative
  • $A$1 — fully absolute
  • A$1 — row locked only
  • $A1 — column locked only

Paste Special is the second most-used

  • Ctrl+Alt+V, V, Enter — paste values
  • Ctrl+Alt+V, T, Enter — paste formats
  • Ctrl+Alt+V, E, Enter — transpose

Auditing a model someone hands you

  • F5 → Special → Constants highlights every hardcoded number
  • Ctrl+[ jumps to a formula's precedents
  • Ctrl+~ toggles "show all formulas" view

The three reflexes you need before day one

  1. Select column: Ctrl+Shift+↓
  2. Paste values: Ctrl+Alt+V, V, Enter
  3. Toggle reference lock: F4

The underscore trick

The _) at the end of the positive format adds an invisible space the width of a closing paren — so positive and negative numbers line up vertically.

Sensitivity Analysis

Every IB deck has a sensitivity table. Excel's Data Table feature builds them automatically.

Data Table — One Variable

  1. Below your output, list the input values in one column
  2. One column to the right, in the row above the first input, type =output_cell
  3. Select the whole rectangle
  4. Alt, A, W, T
  5. Leave Row input blank; in Column input, click the cell that drives your model

Data Table — Two Variables IB

  1. List one set of inputs in a column, the other in a row
  2. In the corner cell type =output_cell
  3. Select the entire grid; Alt, A, W, T
  4. Row input = top-row variable. Column input = left-column variable.

Format the corner cell as ;;; to hide its formula reference.

Goal Seek

"What input makes my output equal X?" Excel solves it.

  1. Alt, A, W, G
  2. Set cell: the output. To value: the target. By changing cell: the input.

Classic IB use: solve for the offer price that gives a target IRR.

Three-Statement Linking

How the income statement, cash flow statement, and balance sheet tie together.

The four critical links

  1. Net Income flows from the bottom of the IS to the top of the CFS
  2. D&A is subtracted on the IS, then added back on the CFS
  3. CapEx in investing on the CFS, increases PP&E on the BS
  4. Ending Cash from CFS becomes cash on next BS. NI (less dividends) flows into Retained Earnings.

The "tie-out" check

BS must satisfy Total Assets = Total Liabilities + Total Equity. Build a check row: =Assets - (Liabilities + Equity) — should be zero.

Circular References & Calculation Modes

Some IB models intentionally rely on circular formulas.

The classic LBO circularity

Interest expense depends on average debt, which depends on cash flow, which depends on interest expense.

Enable iterative calculation:

  1. File → Options → Formulas
  2. Check Enable iterative calculation
  3. Maximum Iterations ≈ 100, Maximum Change ≈ 0.001

Manual vs. Automatic calculation

  • Formulas → Calculation Options → Manual
  • F9 — recalculate workbook
  • Shift+F9 — only the active sheet
  • Ctrl+Alt+F9 — full rebuild

Memory Tips

How to actually remember all of this.

The big secret: you don't have to memorize them at all

Press Alt on its own and Excel displays every keyboard shortcut directly on the ribbon. Tiny letters appear over each tab and button.

So Alt+H, F, I, S means:

  • Press Alt → ribbon lights up with hints
  • Press H → Home tab opens, new letters appear
  • Press F → Fill menu opens
  • Press I, then S → confirms Series

Mnemonic for the ribbon tabs

  • Alt + F → File
  • Alt + H → Home
  • Alt + N → iNsert
  • Alt + P → Page Layout
  • Alt + M → forMulas
  • Alt + A → dAta
  • Alt + R → Review
  • Alt + W → vieW

Patterns that make Ctrl+ shortcuts easier

  • Ctrl + Shift + [number] = number formats (1=number, 4=currency, 5=percent, 7=border)
  • Ctrl + [letter] follows Word equivalents (B/I/U, F find, S save, P print)
  • Ctrl + 9 / Ctrl + 0 = hide rows / columns (9 tall, 0 wide)
  • F-keys: F2 edits, F4 locks, F5 goes to, F9 recalculates
  • + inserts, − deletes

The two rules of getting fast

1. Force the shortcut even when slower at first. By week three your fingers do it automatically.

2. Sit on your mouse hand. A trick analysts use to force keyboard-only workflows.
