Functions & Formulas

The formulas that do the actual work — lookups, conditional logic, financial math, date handling, and text manipulation.

Lookup Functions

Pull a value from one place into another based on a matching key. Mastering these is non-negotiable.

VLOOKUP

Find a value in the leftmost column of a table, return a value from a column to its right.

=VLOOKUP(lookup_value, table_array, col_index, [range_lookup])

Best for:

  • Quick lookups where the data layout is fixed
  • Pulling a single field (price, name, category) using an ID

Watch out for:

  • Can't look left — key column must be column 1
  • Inserting a column inside table_array breaks the formula
  • Slower than INDEX/MATCH on large datasets

Always use FALSE (or 0) as the last argument unless you specifically want approximate match (rare).

Animated example — finds Carol's department
=VLOOKUP("E003", A2:D5, 3, FALSE) → Engineering

INDEX / MATCH

A more flexible two-function combo — works in any direction, survives column changes.

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

How it works in two steps:

  • MATCH finds the row position of the lookup value (e.g., "E003" → 3)
  • INDEX returns the value at that position from the column you choose

Best for IB because:

  • Doesn't break when columns shift around
  • Can look left as well as right
  • Two-way lookups possible (with two MATCH calls)
  • The IB industry standard

XLOOKUP note: Excel 365/2019+ has XLOOKUP which combines both. Use it personally, but learn INDEX/MATCH for compatibility.

Logical & Conditional Functions

Branching logic and conditional aggregation. IFERROR and SUMIFS in particular are used in basically every IB model.

IF

Branch on a condition: do one thing if true, another if false.

=IF(condition, value_if_true, value_if_false)

Examples:

=IF(A1>100, "High", "Low")
=IF(Revenue>Budget, Revenue-Budget, 0)  // only show overage

Nesting: You can nest IFs (=IF(x, a, IF(y, b, c))) but if you find yourself nesting more than 2 deep, switch to IFS or a lookup table — easier to read and audit.

IFERROR IB

Wraps a formula to show a clean fallback when it errors. Used in every model.

=IFERROR(formula, value_if_error)

Common uses:

=IFERROR(VLOOKUP(A1, Data, 2, FALSE), "Not found")
=IFERROR(B1/C1, 0)  // hides #DIV/0!

Without IFERROR, a missing lookup or a divide-by-zero blows up your whole model with red errors. Wrapping it makes the model resilient.

Caution: Don't blanket-wrap everything. Errors are sometimes telling you about a real bug — only suppress them when you genuinely expect missing values.

SUMIFS IB

Sum a range only where multiple conditions are met. The conditional total workhorse.

=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2, ...)

Example: total Q1 revenue from the North region:

=SUMIFS(Revenue, Region, "North", Quarter, "Q1")

Operators in criteria: use ">100", "<=50", "<>A", or "*Inc*" (wildcard) inside quotes.

Sister functions: COUNTIFS (counts rows meeting criteria), AVERAGEIFS (average), MAXIFS/MINIFS (max/min).

COUNTIFS

Count rows where multiple conditions hold.

=COUNTIFS(criteria_range1, criteria1, criteria_range2, criteria2, ...)

Example: count of closed deals in EMEA this year:

=COUNTIFS(Status, "Closed", Region, "EMEA", Year, 2026)

Same syntax as SUMIFS but no sum_range argument — it just counts the matching rows.

Financial Functions

The valuation building blocks. XNPV and XIRR are the dated versions and are usually preferred in IB.

NPV & XNPV IB

Present value of a series of cash flows discounted at a rate.

=NPV(rate, cashflow1, cashflow2, ...)
=XNPV(rate, cashflows, dates)

Critical NPV gotcha: Excel's NPV assumes the first cash flow is at the END of period 1, not period 0. So if you have an initial investment at t=0, add it outside the function:

=A1 + NPV(rate, B1:Z1)  // A1 is the t=0 investment

Use XNPV instead when you have actual dates rather than assumed equal periods. It uses precise day-count and handles t=0 correctly.

IRR & XIRR IB

The discount rate that makes NPV equal zero — i.e., the implied return on a stream of cash flows.

=IRR(cashflows, [guess])
=XIRR(cashflows, dates, [guess])

The first cash flow is typically negative (the initial investment); subsequent cash flows are positive (returns). If you have irregular dates (almost always true in real deals), use XIRR.

Watch out for: If cash flows change sign more than once (negative → positive → negative), there can be multiple IRRs. The [guess] argument helps Excel pick which one to converge on.

PMT

Periodic payment for a loan with constant payments and a constant interest rate.

=PMT(rate, nper, pv, [fv], [type])

Example: monthly payment on a $500k mortgage at 6% APR for 30 years:

=PMT(6%/12, 30*12, 500000)  // returns -2,997.75

The result is negative because it's a cash outflow. In LBO models you'll use PMT to size mandatory debt amortization.

Tip: Make sure the rate and periods match — monthly rate with monthly periods, annual with annual.

Date Functions

For fiscal periods, partial-year discounting, and anything time-aware. EOMONTH alone is worth the price of admission.

End of month, optionally offset by N months IB
=EOMONTH(start, months)
=EOMONTH(TODAY(),0) = last day of this month. =EOMONTH("2026-01-15",11) = Dec 31, 2026 (year-end).
Same date N months later (or earlier with negative)
=EDATE(start, months)
=EDATE("2026-01-15", 12) = Jan 15, 2027.
Fraction of a year between two dates IB
=YEARFRAC(start, end, [basis])
Used for partial-year discounting in DCFs. Common basis: 0 (30/360) or 1 (actual/actual).
Build a date from year/month/day
=DATE(year, month, day)
=DATE(2026,12,31). Useful when assembling dates from formula inputs.
Today's date (auto-updates)
=TODAY()
Volatile — recalculates every time the sheet recalculates. Use Ctrl+; for a static date instead.

Text Functions

Cleaning up data dumps from clients and building dynamic labels.

Format a number as a custom-formatted text string
=TEXT(value, "format")
=TEXT(A1, "$#,##0.00") or =TEXT(TODAY(), "mmm-yy"). Useful in chart titles like "FY"&TEXT(year, "00").
Combine text with the & operator
=A1 & " " & B1
Cleaner than CONCATENATE. Example: ="Q"&A1&" "&B1 → "Q1 2026".
Extract characters from the left, right, or middle
=LEFT(text, n)
Also RIGHT(text, n) and MID(text, start, n). For pulling apart ticker symbols, IDs, etc.
Remove extra spaces (leading, trailing, double)
=TRIM(text)
First thing to try when a VLOOKUP returns #N/A for what looks like a match — invisible trailing spaces are often the culprit.
Length of a text string
=LEN(text)
Quick way to verify two cells really do contain the same text.

Common Formula Recipes

The handful of formulas you'll write hundreds of times in any analyst role.

Year-over-year growth rate
=(B/A) - 1
Format as percentage (Ctrl+Shift+5). Equivalent to (B-A)/A but shorter.
CAGR (compound annual growth rate) IB
=(End/Begin)^(1/Years) - 1
Where Years is the number of years between Begin and End values.
Discount factor for period n IB
=1/(1+rate)^n
Multiplied by a future cash flow gives present value. Building block of any DCF.
Mid-year convention discount factor IB
=1/(1+rate)^(n - 0.5)
Assumes cash flows arrive evenly through the year rather than at year-end. Standard in DCF valuations.
Terminal value (Gordon growth)
=FCF*(1+g) / (r-g)
Where FCF is final-year free cash flow, g is perpetual growth rate, r is discount rate (WACC). Then discount this back to present.
Margin (gross, operating, net)
=Profit / Revenue
Format as percentage. Used in every comps and trading multiples table.

Pro Tips & Conventions

The unwritten rules of IB Excel work.

The font color convention (memorize this on day one)

Every IB model uses the same color code so anyone opening the file can instantly tell what's an input vs. what's calculated:

  • Blue — hardcoded inputs (assumptions, raw data you typed in)
  • Black — formulas computed within the same sheet
  • Green — links to other sheets in the same workbook
  • Red — links to other workbooks (treat as fragile)

Blue = fair game to change. Black = stop, you're about to break a formula.

F4 is your most-used key

While editing a formula, position your cursor on a cell reference and tap F4 to cycle through the four lock options:

  • A1 — fully relative (shifts when copied)
  • $A$1 — fully absolute (locked both directions)
  • A$1 — row locked only
  • $A1 — column locked only

Mixed references (only one $) come up constantly — e.g., locking the year row but not the line item column when copying a sensitivity table.

Paste Special is the second most-used

Three combos every banker memorizes:

  • Ctrl+Alt+V, V, Enter — paste values (kills formulas, keeps numbers)
  • Ctrl+Alt+V, T, Enter — paste formats
  • Ctrl+Alt+V, E, Enter — transpose (rows ↔ columns)

Auditing a model someone hands you

  • F5 → Special → Constants highlights every hardcoded number — anything blue, anything that shouldn't be a formula but is
  • Ctrl+[ jumps to a formula's precedents. F5, Enter jumps back
  • Ctrl+~ (tilde) toggles "show all formulas" view — invaluable for reviewing logic

The three reflexes you need before day one

  1. Select a column of data: Ctrl+Shift+↓
  2. Paste values only: Ctrl+Alt+V, V, Enter
  3. Toggle reference lock: F4

Practice on any spreadsheet — even a personal budget will do.

Custom Number Formats

IB house style requires specific number formats. Press Ctrl+1, choose Custom, and paste any of these into the format string box.

Format string What it shows When to use
#,##0_);(#,##0);- 1,234  |  (1,234)  |  - Standard IB number format. Negatives in parens, dash for zero.
$#,##0.00_);($#,##0.00) $1,234.00  |  ($1,234.00) Dollar amounts to two decimals, parens for negative.
#,##0,;(#,##0,) 1,235  (displays in thousands) One trailing comma divides display by 1,000. Cell still contains the full number.
#,##0,,;(#,##0,,) 1  (displays in millions) Two trailing commas = millions. Use for revenue, market cap, deal sizes.
0.0%;(0.0%) 12.5%  |  (12.5%) Percent with one decimal, parens for negative.
0.0"x" 1.5x  |  12.4x Multiples (EV/EBITDA, P/E). Used in comps tables.
[Red](#,##0) (1,234) shown in red Add to any negative section to color it. Use sparingly.

The underscore trick

The _) at the end of the positive format adds an invisible space the width of a closing paren — so positive and negative numbers line up vertically. Without it, positives shift left of negatives.

Sensitivity Analysis

Every IB deck has a sensitivity table. Excel's Data Table feature builds them automatically.

Data Table — One Variable

Tests how one input affects one (or several) outputs.

Setup:

  1. Below your output formula, list the input values to test in one column (e.g., discount rates 8%, 9%, 10%, 11%, 12%)
  2. One column to the right of the input list, in the row above the first input, type =output_cell
  3. Select the whole rectangle: input list + output reference + the empty cells below it
  4. Press Alt, A, W, T
  5. Leave Row input cell blank; in Column input cell, click the input cell that drives your model
  6. OK

Excel re-runs the model once per row, filling the column with the resulting outputs.

Data Table — Two Variables IB

Tests how two inputs interact (e.g., WACC vs. terminal growth → enterprise value).

Setup:

  1. List one set of inputs in a column (e.g., WACC values)
  2. List the other set in a row (e.g., growth rates)
  3. In the corner cell (top-left of the grid), type =output_cell
  4. Select the entire grid including labels
  5. Alt, A, W, T
  6. Row input cell = the cell that holds your top-row variable. Column input cell = the cell that holds your left-column variable.
  7. OK

You now have a full sensitivity grid. Format the corner cell as ;;; to hide the formula reference.

Goal Seek

"What input value would make my output equal X?" Excel finds it by iteration.

Steps:

  1. Alt, A, W, G
  2. Set cell: the output you want at a target value
  3. To value: the target number
  4. By changing cell: the input cell Excel is allowed to change
  5. OK — Excel solves it

Classic IB use: solve for the offer price that gives a target IRR, or the discount rate implied by a market price.

Three-Statement Linking

A quick conceptual reference for how the income statement, cash flow statement, and balance sheet tie together.

The four critical links

  1. Net Income flows from the bottom of the IS to the top of the CFS (operating section)
  2. Depreciation & Amortization is subtracted on the IS (reduces net income), then added back on the CFS (it's non-cash). Also accumulates on the BS as accumulated D&A.
  3. CapEx shows up in the investing section of the CFS as an outflow, and increases PP&E on the BS
  4. Ending Cash from the bottom of the CFS becomes the cash line at the top of the next period's BS. Net Income (less dividends) flows into Retained Earnings on the BS.

The "tie-out" check

Your balance sheet must satisfy: Total Assets = Total Liabilities + Total Equity. Build a check row at the bottom: =Assets - (Liabilities + Equity). It should equal exactly zero. If it doesn't, you have a bug — usually a missing link, a sign error, or D&A only added in one place.

Circular References & Calculation Modes

Some IB models intentionally rely on circular formulas — knowing how to handle them is essential.

The classic LBO circularity

In an LBO, interest expense depends on average debt balance, which depends on cash flow, which depends on interest expense. Circular by design. Excel chokes unless you tell it iterative calculation is allowed.

Enable iterative calculation:

  1. File → Options → Formulas
  2. Check Enable iterative calculation
  3. Set Maximum Iterations ≈ 100 and Maximum Change ≈ 0.001

Excel will now solve the loop by repeated approximation until the answer stabilizes.

Manual vs. Automatic calculation

Big models can take seconds to recalc. Switch to manual mode so Excel only recalculates when you tell it to:

  • Formulas tab → Calculation Options → Manual (or Alt, M, X, M)
  • F9 — recalculate the entire workbook
  • Shift+F9 — recalculate only the active sheet
  • Ctrl+Alt+F9 — force a full rebuild (use after a structural change)

Common Errors & Fixes

Excel has seven main error types. Each tells you something specific about what went wrong.

Error What it means Most common fix
#N/A A lookup couldn't find a match. Most often from VLOOKUP, INDEX/MATCH, or XLOOKUP. Double-check spelling. Wrap in IFERROR. Use TRIM on both sides — invisible trailing spaces are the #1 cause.
#REF! A reference is invalid — usually because a referenced cell, row, or column was deleted. Look at recent deletes. Undo if possible. Otherwise rewrite the formula.
#VALUE! Wrong type of argument — text where a number is expected, or vice versa. Check that all referenced cells contain the type the formula expects. Numbers stored as text are a common culprit.
#DIV/0! Dividing by zero or by an empty cell. Wrap in IFERROR, or use =IF(denom=0, 0, num/denom) to handle it explicitly.
#NAME? Excel doesn't recognize the function name or named range. Check spelling. Confirm the named range exists. Older Excel versions may not have newer functions like XLOOKUP.
#NULL! You used a space between two ranges that don't intersect. Use a comma between ranges instead of a space. (Space is the rare "intersection" operator.)
##### The column is too narrow to display the value (or a date is negative). Widen the column — double-click the right edge of the column header to auto-fit.

Memory Tips

How to actually remember all of this — especially the long Alt+letter+letter ribbon sequences.

The big secret: you don't have to memorize them at all

Press Alt on its own and Excel displays every keyboard shortcut directly on the ribbon. Tiny letters appear over each tab and button. Press the letter for the tab you want, and a new set of letters appears for that tab's buttons. You can read off the keyboard path one step at a time.

So Alt+H, F, I, S means:

  • Press Alt → ribbon lights up with letter hints
  • Press H → opens Home tab, new letters appear
  • Press F → opens Fill menu
  • Press I, then S → confirms Series

After a few uses, your fingers learn the sequence on their own.

Mnemonic for the ribbon tabs

The first letter after Alt picks the tab. Mostly logical:

  • Alt + F → File
  • Alt + H → Home (most formatting)
  • Alt + N → iNsert (charts, tables, pivots)
  • Alt + P → Page Layout
  • Alt + M → forMulas
  • Alt + A → dAta (sort, filter, data tables)
  • Alt + R → Review
  • Alt + W → vieW (freeze panes, zoom)

Patterns that make Ctrl+ shortcuts easier to remember

  • Ctrl + Shift + [number] = number formats (1=number, 4=currency, 5=percent, 7=border)
  • Ctrl + [letter] follows Word equivalents (B/I/U for bold/italic/underline, F for find, S for save, P for print)
  • Ctrl + 9 / Ctrl + 0 = hide rows / hide columns (9 looks tall, 0 looks wide)
  • F-keys: F2 edits, F4 locks, F5 goes to, F7 spell-checks, F9 recalculates
  • + inserts, − deletes: Ctrl+Shift++ inserts, Ctrl+− deletes — they're literally the math symbols

The two rules of getting fast

1. Force the shortcut even when it's slower at first. Week one feels like sand in the gears. By week three, your fingers do it automatically and you save real time.

2. Sit on your mouse hand. Literally. A trick IB analysts use to force themselves into keyboard-only workflows for a day. You learn fast.
